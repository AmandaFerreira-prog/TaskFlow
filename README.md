# TaskFlow

Aplicação web de gerenciamento de tarefas desenvolvida com HTML, CSS e JavaScript.

O projeto permite criar, editar, concluir e excluir tarefas, mantendo os dados salvos no navegador através do LocalStorage.

## Funcionalidades

- Criar tarefas
- Editar tarefas
- Concluir tarefas
- Excluir tarefas
- Definir categoria
- Definir prioridade
- Definir data
- Persistência dos dados com LocalStorage
- Geração automática de IDs

## Tecnologias

- HTML5
- CSS3
- JavaScript
- LocalStorage
- JSON

## Como executar

1. Clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.

## Projeto

Este projeto foi desenvolvido como prática de JavaScript, com foco em manipulação do DOM, eventos, arrays, objetos, funções e persistência de dados.
